# CardPulse v0.2.0-beta.3

本版完善奖赏计算说明和按日期核对交易的流程，保持默认离线运行及本机加密保存。

## 下载与升级

| 系统 | 安装包 |
| --- | --- |
| macOS 13+ · Apple 芯片 | `CardPulse-0.2.0-beta.3-mac-arm64.dmg` |
| macOS 13+ · Intel | `CardPulse-0.2.0-beta.3-mac-x64.dmg` |
| Windows 10 / 11 · x64 | `CardPulse-0.2.0-beta.3-win-x64.exe` |

Mac 同时提供 ZIP。可用 `SHA256SUMS.txt` 核对下载文件的 SHA-256。

升级前建议导出 `.cardpulse` 加密备份，然后退出旧版再安装。新版沿用原有应用数据目录和加密库格式；不要手动删除保险库或系统应用数据目录。忘记密码无法恢复加密记录。

## 本次更新

- **Pulse 计算明细**：展示人民币／港币基础返现、年度额外奖赏、两半年额度及本年度退款扣回；逐笔说明适用范围、排除原因和待确认渠道。
- **自定义活动说明**：展示净消费门槛、消费与奖赏封顶、剩余额度和实际退款扣回；说明计入或排除的首个原因，支持筛选及每页 25 笔分页。
- **日期筛选**：按记账起止日期查阅与导出，包含起止当天；支持重置，日期倒置时提示并禁止导出。表格筛选不改变奖赏估算范围。
- **工作区维护**：清空数据或成功恢复备份后清理活动草稿，失败／取消恢复保留当前草稿；删光尚未保存的导入交易后正确恢复空库状态。
- **备份与汇率**：只有手动汇率的工作区也可导出加密备份；缺少汇率时，港币相关人民币折算明确显示待折算。
- 简体／繁體界面和简中、繁中、英文 README 同步更新。计算说明按需生成，不改变加密库结构。

本版补充现有模型的解释，不代表最新银行条款或登记资格已获核验。Pulse 当前模型先合并两个半年封顶后的奖赏，再按本年度匹配退款扣回；不追溯退款原单，不回补已使用额度。自定义活动仍独立估算，不自动叠加。封顶按周期汇总，不分配为单笔奖赏。

## 验证与已知限制

- 68 项核心测试、9 项浏览器回归、生产构建通过；另以 300 组混合数据对照原 Pulse 计算器，结果一致。
- Apple 芯片 Mac 打包应用通过启动、离线 PDF、Pulse 说明、人工修正、备份恢复、结单删除及重启持久化测试；Intel 包通过 Rosetta 验证，非 Intel 硬件验收。
- Windows x64 安装包由 macOS 交叉构建，检查可执行文件、离线资源与应用版本；**尚未经过原生 Windows 运行验收**。
- Mac 使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证；Windows 无 Authenticode 发布者签名。首次启动可能出现系统提示，请核对来源及校验和后按系统提示决定是否运行。
- 暂无自动更新、云同步或遥测。更多银行原生 PDF、阶梯／积分模型等支持边界以 README 为准。

## English

This beta adds Pulse calculation breakdowns, shared paginated transaction explanations for Pulse and custom campaigns, posting-date filters, campaign draft cleanup, and rate-only encrypted backups. Missing FX conversions remain unknown. Existing calculation results and the encrypted workspace format are preserved.

68 core tests and 9 browser tests pass. A 300-dataset comparison matches the previous Pulse calculator exactly. Mac packages are tested on Apple silicon, with Intel builds exercised through Rosetta. Windows builds are cross-compiled and statically checked, without native Windows runtime acceptance testing. Mac downloads use ad-hoc signing without Developer ID notarization; Windows downloads are unsigned.

Export an encrypted backup and quit the old app before installing. Mac ZIP downloads and a SHA-256 manifest are included. No automatic updater is provided.
