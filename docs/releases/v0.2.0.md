# CardPulse v0.2.0

安装包于 2026-11-13 更新，版本号仍为 v0.2.0，原下载链接保持不变。已下载旧包的用户请重新下载，并使用最新 `SHA256SUMS.txt` 核对；同一版本号不代表文件内容相同。

## 下载与升级

| 系统 | 安装包 |
| --- | --- |
| macOS 13+ · Apple 芯片 | `CardPulse-0.2.0-mac-arm64.dmg` |
| macOS 13+ · Intel | `CardPulse-0.2.0-mac-x64.dmg` |
| Windows 10 / 11 · x64 | `CardPulse-0.2.0-win-x64.exe` |

Mac 同时提供 ZIP，所有下载均提供 SHA-256 校验清单。

升级前导出 `.cardpulse` 加密备份并退出旧版，然后覆盖安装。应用标识、数据目录、密码、加密算法及备份文件封装不变，新版可读取旧数据，无需重新导入；不要删除原应用数据目录。含分段活动的工作区／备份使用内部数据第 3 版，旧的同版本安装包不支持此模型，请保留升级前备份并使用本次更新的应用读取新数据。忘记密码无法恢复。暂不支持自动更新，请手动下载替换。

## 本次新增

- **同版本构建辨识**：页面底部显示版本、源码提交、UTC 构建时间及构建时源码状态，支持复制公开信息和手动复制文本。桌面复制接口仅复制固定构建元数据，不读剪贴板或账本，不接受任意文本／路径。运行中的构建身份在启动时固定；不替代 SHA-256 校验或发行签名。
- **活动复制与规则分享**：独立复制活动；规则 JSON 导出不含交易和卡号，导入前可预览，整批校验、追加而不覆盖。导入或复制后须重新核对资格；明文规则仍包含活动名称与商户关键词，请检查后分享。
- **自定义结单周期**：可设每月 1–31 日结单，短月取月末，正确处理闰年及跨年；门槛和额度随周期重置，明细显示完整周期。假期及真实结单日调整仍需人工核对。
- **分段累进费率**：2–8 段，各段仅计算对应区间消费；与门槛、消费上限、奖赏上限及退款扣回配合。支持逐段说明、规则分享、加密保存及备份恢复；不等同于达标后全部消费改用高费率。
- **活动管理**：名称／商户关键词搜索，按日期状态或待确认资格筛选；不改变奖赏或规则导出的范围。
- **奖赏核对表**：导出每周期消费、退款、门槛、封顶、扣回及奖赏合计。CSV 明文包含活动名称和汇总金额，不含逐笔交易或卡号，采用统一公式注入防护；不替代加密备份。
- **活动消费试算**：按金额及日期比较新增消费前后的目标周期奖赏、门槛差额和剩余额度。固定／分段费率共用正式引擎，展示未来日期截止口径及可能的负增量。仅在内存中，不改变真实账本或备份。
- **逐笔说明筛选**：Pulse 和自定义活动均支持计入状态、具体原因及商户描述的组合筛选、一键重置和分页。交易修正后实时更新，选定原因变为零笔时仍保留选择。
- **发布校验加强**：对包内全部桌面代码、网页构建资源与本地源码逐文件比对，检查架构、签名与压缩包完整性。

## 保留的功能

默认离线、多银行标准 CSV、HSBC 指定布局原生 PDF、交易人工核对与结单删除、日期筛选、Pulse 明细、保险库改密、本地备份提醒、空闲自动锁定、多标签冲突保护、简体／繁體中文及四种配色均保留。主密码不缓存；未保存内容、编辑草稿或进行中任务会暂缓自动锁定。网页、桌面共用加密备份格式，但读取方须支持备份内的活动模型。

## 验证与已知限制

- 124 项核心测试、26 项浏览器回归及生产构建通过。
- Mac 双架构包检查签名、DMG／ZIP 完整性、离线 PDF 资源与全部桌面／网页文件一致性；Apple 芯片原生运行，Intel 包通过 Rosetta 验证，非 Intel 硬件验收。打包应用完成导入、核对、加密保存、备份恢复、改密和重启烟测。
- Windows x64 包由 macOS 交叉构建并做静态校验，**尚未经过原生 Windows 运行验收**。
- Mac 为 ad-hoc 签名，无 Apple Developer ID 签名或公证；Windows 无 Authenticode 发布者签名。正式版本号不改变这些限制。
- 所有奖赏均为按配置的独立估算，须人工核验银行条款及资格；不自动叠加活动，不追溯退款原单、不回补额度。分段退款从最高已用区间向下扣回，不代表银行统一处理方式。暂不支持积分、达标后全额变更费率、更多银行原生 PDF、云同步或遥测。
