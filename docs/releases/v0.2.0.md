# CardPulse v0.2.0

安装包于 2026-11-05 更新，版本号仍为 v0.2.0，原下载链接保持不变。已下载旧包的用户请重新下载，并使用本次更新的 SHA-256 清单核对。

## 下载与升级

| 系统 | 安装包 |
| --- | --- |
| macOS 13+ · Apple 芯片 | `CardPulse-0.2.0-mac-arm64.dmg` |
| macOS 13+ · Intel | `CardPulse-0.2.0-mac-x64.dmg` |
| Windows 10 / 11 · x64 | `CardPulse-0.2.0-win-x64.exe` |

Mac 同时提供 ZIP，所有下载均提供 `SHA256SUMS.txt` 校验清单。

升级前导出 `.cardpulse` 加密备份并退出旧版，然后覆盖安装。新版沿用现有应用标识、数据目录、密码和加密库格式，无需重新导入；不要删除原应用数据目录。忘记密码无法恢复加密数据。应用暂不提供自动更新，后续可从 GitHub Releases 下载安装新版。

## 本次更新

- **保险库改密**：仅重新加密已保存的数据，保留当前未保存修改；旧备份继续使用原密码，失败或冲突不会替换原库。
- **本地备份提醒**：支持每 7／14／30 天或关闭。桌面文件写入成功才记录日期；网页版须确认文件已保存。旧导出不能清除更新后的改密／恢复提醒。
- **空闲自动锁定**：默认关闭，可选 5／15／30 分钟。未保存内容、编辑草稿、应用内对话框或任务会暂缓锁定；解除后重新计时，休眠返回检查期限。手动锁定前也会确认是否丢弃草稿。
- **草稿清理**：锁定后清理未应用汇率输入与页面状态，已应用的等值汇率不会被误判为尚在编辑。

- **日期自动刷新**：按香港日期每 30 秒检查截止日，重新聚焦窗口或页面可见性变化时也会检查。Pulse、自定义活动和已展开的逐笔说明同步更新，跨日、半年及年度切换不再需要修改数据触发计算。
- **浏览器多标签冲突保护**：保存、恢复和清空在同一个 IndexedDB 事务中检查密文是否变化，阻止旧页面覆盖新修改或写回已删除数据。冲突时保留当前页面修改，可先导出加密备份，再刷新或锁定后解锁最新数据；不自动合并。网页用户升级后需重新加载所有旧标签页。
- 保留此前的多银行标准 CSV、HSBC 原生 PDF、交易核对与结单删除、日期筛选、自定义现金回赠活动、Pulse 计算明细和逐笔说明。
- 默认离线、本机加密存储，继续支持简体／繁體中文、四种配色及跨网页／桌面的加密备份；三语言 README 同步更新。

## 验证与已知限制

- 87 项核心测试、19 项浏览器回归及生产构建通过。
- Mac 安装包检查架构、签名、DMG／ZIP 完整性、离线 PDF 资源及打包源码一致性；Apple 芯片原生运行，Intel 包通过 Rosetta 验证，非 Intel 硬件验收。打包应用完成导入、人工核对、汇率保存、加密备份恢复和重启持久化测试。
- Windows x64 包由 macOS 交叉构建并做静态校验，**尚未经过原生 Windows 运行验收**。
- Mac 仅使用 ad-hoc 签名，无 Apple Developer ID 签名或公证；Windows 无 Authenticode 发布者签名。正式版本号不改变这些签名与验证限制。
- 内置奖赏模型仍需人工核验银行最新条款与资格；退款不追溯原交易、不回补额度，自定义活动独立估算。暂不支持更多银行原生 PDF、阶梯／积分活动、自动更新、云同步或遥测。
