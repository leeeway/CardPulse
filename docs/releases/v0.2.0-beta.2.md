# CardPulse v0.2.0-beta.2

macOS / Windows 本地桌面测试版。结单解析、奖赏估算和加密保存均在本机完成，无需账号或业务服务器。

## 下载与升级

| 系统 | 安装包 |
| --- | --- |
| macOS 13+ · Apple 芯片 | `CardPulse-0.2.0-beta.2-mac-arm64.dmg` |
| macOS 13+ · Intel | `CardPulse-0.2.0-beta.2-mac-x64.dmg` |
| Windows 10 / 11 · x64 | `CardPulse-0.2.0-beta.2-win-x64.exe` |

Mac 同时提供 ZIP。下载后可与 `SHA256SUMS.txt` 比对 SHA-256。

升级前建议在旧版导出 `.cardpulse` 加密备份，然后退出应用，再安装新版。新版继续使用原有应用数据目录；忘记密码无法恢复加密数据。不要手动删除保险库文件或应用数据目录。

## 本次更新

- **交易核对**：修正分类与支付渠道，立即重新计算 Pulse 及自定义活动奖赏；保留修改前后记录，随加密库与备份保存。
- **结单删除**：按导入关联删除指定结单及交易，保留其他结单、活动和汇率；删除后可重新导入。旧版导入记录仍可关联。
- **CSV 导出**：增加当前支付渠道，便于查阅修正结果。
- **恢复保护**：检查数据版本、重复记录 ID、交易与结单嵌套字段、修改记录；损坏或不支持的数据在恢复前被拒绝。
- 同步简体、繁體中文界面及简中、繁中、英文 README。

交易修正和结单删除均需点击“保存到加密库”才持久保存。删除结单时，关联交易的人工修正记录也会删除；原始 PDF / CSV 文件不受影响。选择支付渠道不会自动确认活动登记资格。

## 验证与已知限制

- 63 项核心测试、3 项浏览器回归通过；Mac Apple 芯片安装包进行真实启动、加密 PDF、交易修正、备份恢复、结单删除及重启持久化验证。Intel 包通过 Apple 芯片机器上的 Rosetta 验证，并非 Intel 硬件验收。
- Windows 安装器由 macOS 交叉构建，检查 x64 可执行文件及离线资源；**尚未进行原生 Windows 运行验收**。
- Mac 使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证；Windows 没有 Authenticode 发布者签名。首次启动可能出现系统提示，请核对来源与校验和后按系统提示决定是否运行。
- 暂无自动更新、云同步或遥测。保留默认离线运行及手动汇率；仅主动更新参考汇率时联网。其他银行原生 PDF 及复杂奖赏模型仍以 README 支持范围为准。

## English

This desktop beta adds transaction category/channel corrections with encrypted change history, immediate reward recalculation, selective statement deletion, payment channels in CSV exports, and stricter vault/backup validation. Changes persist after a manual vault save. Back up your encrypted vault and quit the previous app before upgrading.

Downloads cover macOS 13+ on Apple silicon and Intel, plus Windows 10/11 x64. Mac ZIP archives and a SHA-256 manifest are included. Mac packages use ad-hoc signing without Developer ID notarization; Windows packages are unsigned. Intel Mac tests use Rosetta. Windows builds are cross-compiled and statically checked, without native Windows runtime acceptance testing. No automatic updater is included.
